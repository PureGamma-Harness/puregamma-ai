# Inter variable font

Self-hosted Latin variable-weight Inter, distributed by `@fontsource-variable/inter`
version 5.3.0. The unmodified font is provided under the SIL Open Font License
in [OFL-Inter.txt](OFL-Inter.txt). Chinese text uses the system CJK fallback.

Source: https://www.npmjs.com/package/@fontsource-variable/inter/v/5.3.0

copying `files/inter-latin-wght-normal.woff2` to the public asset name.
