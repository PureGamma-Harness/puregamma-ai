# Dashboard and readable-content upgrade

## Execution prompt and evidence

Work from PureGamma's existing product and approved runtime. Make the overview
useful before adding decoration: preserve a user's question, show source/data
availability truthfully, and put the next real action in the first screen.
Use one compact page heading and a stable reading hierarchy, rather than a
marketing hero inside an authenticated workspace. Keep release gates, session
ownership, real API boundaries and existing business/error checks intact.

The baseline command surface writes `prompt`, but Chat only reads `topic`, so
the primary question handoff loses the draft. Its Chinese suggestion buttons
also submit the English label. Hero stages reveal sequentially over about three
seconds, including the primary input. Settled desktop screenshots still place
the next workflow row around 650px. Retrieved Markdown can also introduce a
second page-level heading when embedded without an outline context.

## Acceptance

- A typed or suggested question reaches an editable localized Agent draft;
  navigation itself never sends a message or starts a paid run.
- The overview has one compact h1, accessible primary question input and real
  workflow links without waiting for a decorative reveal.
- Data freshness refers to actual source timestamps; missing data never becomes
  a current clock, zero balance or fabricated live market status.
- Embedded Markdown retains its text, relative outline, safe URLs and internal
  table/code scrolling without competing with the workspace h1.
- Both appearances, both themes, keyboard access and reduced motion work in
  the real browser. Local screenshots and independent product review are
  separate from engineering CI.

Inter is self-hosted from its verified Fontsource 5.3.0 archive with its SIL OFL
license, replacing an unfulfilled font-family declaration without adding a
runtime package or external font request.
